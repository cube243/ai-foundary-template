# ADR-0010: オフライン評価(CI/CDのゲート)とオンラインA/Bテストを分離し、後者をテンプレート本体に含めない

## ステータス
承認済み

## コンテキスト
LLM/RAGアプリケーションの品質保証には大きく2種類のアプローチがある。1つはCI/CDパイプライン内で既知の入力に対する既知の期待値(または評価基準)を使って自動的にゲートするオフライン評価で、もう1つは本番トラフィックの一部を使って複数のバリエーション(プロンプト、モデル、RAG構成等)を比較検証するオンラインA/Bテストである。後者はAWSではAppConfig+Bedrock Prompt Managementの組み合わせで構成されることが多い。また、CloudWatch Evidently(A/Bテスト用のマネージドサービス)は2025年10月に廃止されている。

## 決定
オフライン評価(CI/CDのゲート)とオンラインA/Bテストを明確に分離する。オンラインA/Bテスト(AppConfig + Prompt Managementの構成)は本テンプレート群には含めず、別途サンプルコードとして提供する。CloudWatch Evidentlyは廃止済みのため参照・使用しない。

## 検討した代替案
- **オンラインA/Bテストの基盤(AppConfig+Prompt Management)を各エージェントテンプレートに組み込む**: A/Bテストの設計(トラフィック分割比率、評価指標の選定、統計的有意性の判断等)はプロジェクトごとの実験文化・組織のガバナンスに強く依存し、Terraformテンプレートとして汎用的に固定化するには適さないと判断した。
- **CloudWatch Evidentlyを使う**: 2025年10月に廃止されたサービスであり、新規に依存を作ることはできない。

## 結果・トレードオフ
得られるもの: 本テンプレート群はCI/CDで再現可能なオフライン評価に集中でき、実験基盤の設計自由度を利用者側に残せる。廃止済みサービスへの依存を避けられる。
引き換えに受け入れるもの: オンラインA/Bテストを行いたい利用者は、提供されるサンプルコードを参考に自分たちの環境向けに構築する必要があり、テンプレートをapplyするだけでは手に入らない。
